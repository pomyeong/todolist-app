## 2. 운영 배포 구성 확인

- 모든 API 요청이 프론트 주소(`todolist-pmsong.vercel.app/api/...`)로 나가 같은 출처 쿠키(`SameSite=Lax`)로 인증이 유지된다. `page.goto`로 전체 새로고침해도 로그인이 유지됐다.
- `/api/health` 응답 시간(rewrite 경유): 첫 요청 1.35s, 이후 0.46~0.72s.
