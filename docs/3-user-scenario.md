## 3. 시나리오 상세

### 3.0 공통 전제

**기준 날짜**: 오늘 = 2026-11-04(수), 사용자 단말 현지 날짜(도메인 2장 '오늘'). 상태가 포함된 조회는 `today=2026-11-04`로 요청한다(P-12, NFR-12).

**달력 참고**: 2026-11-01은 일요일이다. 주 뷰(BR-17) 기준 주는 10-25~10-31, 11-01~11-07, 11-08~11-14.

**예시 데이터**: 사용자 U1의 카테고리는 '기본'(BR-10), '업무', '학습'. 할일은 다음과 같다.

| 할일 | 제목 | 카테고리 | 시작일 ~ 종료일 | 완료 여부 | 상태(오늘 기준) | 판정 근거 |
|---|---|---|---|---|---|---|
| T1 | 보고서 작성 | 업무 | 2026-10-28 ~ 2026-11-03 | false | 지연 | ST-04 (오늘 > 종료일) |
| T2 | 시험 공부 | 학습 | 2026-11-02 ~ 2026-11-10 | false | 진행 중 | ST-03 |
| T3 | 여행 준비 | 기본 | 2026-11-20 ~ 2026-12-02 | false | 시작 전 | ST-02 (오늘 < 시작일) |
| T4 | 장보기 | 기본 | 2026-11-04 ~ 2026-11-04 | true | 완료 | ST-01 (날짜 무관) |

다른 사용자 U2는 카테고리 C9, 할일 T9를 가진다(소유권 예외 검증용).

**공통 예외 흐름**(로그인이 필요한 SC-03~SC-12에 모두 적용, 각 시나리오에서 반복하지 않음):

| ID | 조건(위반 규칙) | 응답(NFR-15) | 결과 |
|---|---|---|---|
| E-C1 | 인증 쿠키 없음·만료·위조 상태로 API 호출(BR-01, FR-04, P-04) | 401 `UNAUTHORIZED` | 요청이 처리되지 않고, 화면은 로그인 화면(SCR-01)으로 이동한다(FR-04). |
| E-C2 | U2의 카테고리 C9·할일 T9를 조회·수정·삭제·지정(BR-03, BR-04, NFR-07) | 404 `NOT_FOUND` | 존재하지 않는 경우와 같은 응답, 데이터 변경 없음 |
| E-C3 | 서버 내부 오류 | 500 `INTERNAL_ERROR` | 내부 상세는 응답에 포함되지 않는다(NFR-15). |

**오류 표시**: 각 시나리오의 400 `VALIDATION_ERROR`는 해당 입력란 옆에, 그 밖의 오류는 폼 상단(폼이 없는 목록·캘린더는 화면 상단)에 사유를 표시한다(PRD 4장 머리말). 각 예외 표에서 반복하지 않는다.

### SC-01 회원가입

- **사전 조건**: 비로그인 상태. `u1@example.com`으로 가입한 사용자가 없다.

| 단계 | 사용자 행동 | 시스템 반응 | 화면 |
|---|---|---|---|
| 1 | SCR-01에서 회원가입 이동 링크를 누른다. | 회원가입 화면을 표시한다. | SCR-01 → SCR-02 |
| 2 | 이메일 `u1@example.com`, 비밀번호 8자 이상 64자 이하(BR-21), 같은 값의 비밀번호 확인(P-24), 이름을 입력하고 가입한다. | 사용자와 '기본' 카테고리를 한 트랜잭션으로 생성한다(BR-10, NFR-10). | SCR-02 |
| 3 | - | 인증 쿠키를 발급하고(자동 로그인, P-04) 할일 목록으로 이동한다(FR-01). 목록은 0건이다. | SCR-02 → SCR-03 |

- **대안 흐름**: 이메일·이름의 앞뒤 공백은 제거한 뒤 검사·저장한다(BR-22).

| ID | 조건(위반 규칙) | 응답(NFR-15) | 결과 |
|---|---|---|---|
| E-01-1 | 이미 가입된 이메일(BR-02) | 409 `DUPLICATE_EMAIL` | 사용자 미생성 |
| E-01-2 | 비밀번호 7자 또는 65자(BR-21) | 400 `VALIDATION_ERROR` | 사용자 미생성 |
| E-01-3 | 이메일 형식 오류(NFR-09), 이메일 255자·이름 51자(BR-22), 이름이 공백만 있음(BR-22) | 400 `VALIDATION_ERROR` | 사용자 미생성 |
| E-01-4 | 비밀번호와 비밀번호 확인이 다름(P-24) | 요청 미전송(화면 검사) | 확인란 옆에 불일치 사유 표시, 사용자 미생성 |

- **사후 조건**: U1이 존재하고 U1의 카테고리는 '기본' 정확히 1개다(FR-01). U1은 로그인 상태다.

### SC-02 로그인 / 로그아웃 / 인증 보호

- **사전 조건**: U1 가입 완료, 비로그인 상태.

| 단계 | 사용자 행동 | 시스템 반응 | 화면 |

|---|---|---|---|
| E-02-1 | 비밀번호 틀림, 또는 가입되지 않은 이메일 | 401 `INVALID_CREDENTIALS` (두 경우 구분 없음, FR-02) | 쿠키 미발급 |
| E-02-2 | 쿠키 없이 회원가입·로그인 외 API 호출(BR-01) | 401 `UNAUTHORIZED` | 요청 미처리(FR-04) |
