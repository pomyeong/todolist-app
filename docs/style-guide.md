### 2.2 상태색 (ST-01~04)

목록의 상태 칩, 캘린더 칸 안 항목 막대, 모바일 개수 점에 같은 쌍을 쓴다.

| 상태 | `data-status` | 배경 토큰 / 값 | 글자 토큰 / 값 | 대비 |
|---|---|---|---|---|
| 진행 중(ST-03) | `in_progress` | `--st-progress-bg` `#6a5ae0` | `--st-progress-fg` `#ffffff` | 5.1:1 |
| 시작 전(ST-02) | `not_started` | `--st-todo-bg` `#f0eefd` | `--st-todo-fg` `#4b3fb8` | 6.8:1 |
| 지연(ST-04) | `overdue` | `--st-overdue-bg` `#c24e28` | `--st-overdue-fg` `#ffffff` | 4.8:1 |
| 완료(ST-01) | `completed` | `--st-done-bg` `#e8eaed` | `--st-done-fg` `#5f6368` | 5.1:1 |

- 빨강(`--danger`)은 오류·삭제 전용이라 '지연'에는 주황을 쓴다. 상태와 오류를 색으로 혼동하지 않게 한다.
- 완료는 회색으로 가라앉힌다. 목록 행의 완료 할일 제목은 `--text-muted`로 바꾸고 취소선은 쓰지 않는다(제목 판독 유지).

## 5. 컴포넌트

### 5.1 버튼

| 종류 | 모양 | 쓰임 |
|---|---|---|
| 주 버튼 `.primary` | 배경 `--primary`, 흰 글자, hover `--primary-strong` | 저장, 로그인, 가입, 등록 이동 |
| 보조 버튼(기본) | 배경 `--bg`, 테두리 `--border`, 글자 `--text` | 취소, 이전/다음, 로그아웃 |
| 위험 버튼 `.danger` | 배경 `--danger`, 흰 글자 | 대화상자의 삭제 '확인' |
| 텍스트 버튼 | 테두리·배경 없음, 글자 `--primary-text` | '+N', 행 안 '수정' |

- 높이 36px(모바일 40px), 좌우 `--space-4`, 모서리 `--radius-sm`.
- 비활성(P-22 저장 중 포함)은 `opacity: 0.5`, `cursor: not-allowed`.
- 이전/다음 버튼은 32×32px 정사각, 글자 대신 `‹` `›`, `aria-label`로 '이전 달' 등.

### 5.2 세그먼트(월/주/일, L-09)

- 버튼 3개를 붙여 한 묶음으로, 각 높이 32px, 글자 `--fs-sm`.
- 비선택: 배경 `--surface-muted`, 테두리 `--border`, 글자 `--text`. 선택: 배경 `--primary`, 테두리 `--primary`, 흰 글자, `aria-pressed="true"`.
- 묶음 양 끝만 `--radius-sm`, 사이 모서리는 0.

### 5.3 입력란·선택 상자·날짜 선택기

- 높이 40px, 테두리 `--border`, 모서리 `--radius-sm`, 포커스 시 테두리 `--primary` + 포커스 링(5.8).
- 라벨은 입력란 위, `--fs-sm`, `--text-strong`. 필수 표시는 따로 두지 않는다(서버 검증 문구로 안내, NFR-15).
- 오류 상태: 테두리 `--danger`, 아래 필드 오류 문구 `--fs-sm` `--danger`(`FieldError`).
- 날짜는 브라우저 기본 `<input type="date">`를 쓴다(새 라이브러리 금지, PRD 3.2).

### 5.4 상태 칩

- `.chip[data-status]`: 높이 22px, 좌우 `--space-2`, `--radius-pill`, `--fs-sm`, 2.2의 색 쌍.
- 목록 행·그날 목록에서 쓴다. 캘린더 칸 안에서는 칩 대신 5.6의 막대를 쓴다.

### 5.5 공통 내비게이션(WF-01, L-04)

- 높이 데스크톱 56px(한 줄), 모바일 두 줄. 배경 `--bg`, 아래 1px `--divider`.
- 앱 이름·로고는 두지 않는다(WF-01 구성 요소에 없음).
- 이동 링크: `--fs-md`, `--text`. 현재 화면 링크는 배경 `--primary-soft`, 글자 `--primary-text`, 700, 모서리 `--radius-sm`.
- 사용자 이름 `--text-muted`, 로그아웃은 보조 버튼.

### 5.6 캘린더 (WF-06~08)

적용 예: [WF-06 데스크톱 월 뷰](./wireframe/sg-wf-06-calendar-month.svg) (시나리오 3.0 데이터, 오늘·선택 = 2026-11-04)

**컨트롤 줄**(L-09): 왼쪽 세그먼트(5.2), 그 오른쪽에 이전 버튼 · 기간 라벨 · 다음 버튼. 기간 라벨 문구는 와이어프레임(`2026-11`, `2026-11-01 ~ 2026-11-07`, `2026-11-04 (수)`)을 따르고, 모양은 `--fs-lg` 700 `--text-strong` `tabular-nums`.

**격자(데스크톱 월·주)**

| 요소 | 규칙 |
|---|---|
| 요일 줄 | 높이 32px, 배경 `--surface-muted`, `--fs-xs` `--text-muted`, 왼쪽 정렬. 일요일만 `--sunday` |
| 날짜 칸 | 격자선 1px `--divider`, 안쪽 여백 `--space-1`, 월 뷰 최소 높이 104px(항목 3건 + '+N'이 들어가는 높이) |
| 날짜 숫자 | 칸 왼쪽 위, `--fs-sm`. 일요일 `--sunday`, 다른 달 `--text-hint` |
| 오늘 | 칸 배경 `--today-bg`, 숫자 700 |
| 선택된 날짜(P-20, L-10) | 칸 안쪽 2px 테두리 `--primary`(`box-shadow: inset 0 0 0 2px`) |
| 칸 안 항목 | 높이 20px 막대, 칸 폭 가득, `--radius-xs`, `--fs-xs`, 2.2 상태색. 글자는 '제목 (상태)' 한 줄 말줄임(P-21). 항목 사이 2px |
| '+N' | 텍스트 버튼, `--fs-xs`, `--primary-text` |

- 같은 할일이 여러 날에 걸치면 칸마다 같은 색 막대로 반복 표시한다(P-16). 칸을 넘는 하나의 긴 막대는 만들지 않는다(BR-17 칸 단위 표시).

**모바일 월·주(SCR-05 모바일, P-20)**: 칸에 날짜 숫자와 그 아래 개수 표시(지름 6px 점 `--primary` + 숫자 `--fs-xs` `--text-muted`). 0건은 아무것도 두지 않는다. 오늘·선택 표시는 데스크톱과 같다.

**일 뷰와 그날 목록(WF-08, L-10)**: 시간 축은 두지 않는다(할일에 시각 없음). 제목 `--fs-lg` 700(날짜), 행은 `--fs-md`, 행 사이 1px `--divider`, 오른쪽에 상태 칩(5.4).

### 5.7 목록 행·카드(WF-04, L-06)

- 데스크톱 표: 머리줄 배경 `--surface-muted` `--fs-sm` `--text-muted`, 행 높이 48px, 행 구분 1px `--divider`, hover 배경 `--surface-muted`.
- 모바일 카드: 테두리 1px `--divider`, `--radius-md`, 안쪽 `--space-3`, 카드 사이 `--space-2`.
- 기간은 `--text-muted` `tabular-nums`. 제목은 링크(`--text-strong`, 밑줄 없음, hover 밑줄).

### 5.8 피드백 요소

| 요소 | 규칙 |
|---|---|
| 화면·폼 상단 오류(L-17, `FormError`) | 배경 `--danger-soft`, 왼쪽 3px `--danger` 선, 글자 `--danger`, 안쪽 `--space-3`, `role="alert"` |
| 조회 중(`LoadingNotice`) | `--text-muted` `--fs-md` 한 줄. 스피너 이미지는 쓰지 않는다 |
| 빈 상태(`EmptyNotice`, L-18) | 가운데 정렬, `--text-muted`, 위아래 `--space-6` |

## 7. 코드 적용 현황 (v0.2)
